# 방언 퀴즈 대항전 — 독립 공유용 사이트

Floot와 무관하게 운영하는 정적 웹사이트 + Supabase(PostgreSQL) 버전입니다.

## 준비
1. https://supabase.com 에서 새 프로젝트를 생성합니다.
2. SQL Editor에서 `supabase.sql` 전체를 실행합니다. **기존 프로젝트에 실행하지 말고 새 프로젝트에서 실행하세요.**
3. Project Settings → API Keys에서 `Project URL`과 `anon`/`publishable` key를 확인합니다. **service_role 키를 사용하지 마세요.**
4. `config.js`의 두 값을 입력합니다.
5. `index.html`, `style.css`, `app.js`, `config.js`를 GitHub 저장소 루트에 올리고 Settings → Pages에서 `Deploy from a branch`를 설정합니다. 또는 정적 웹 호스팅 서비스에 네 파일을 올립니다.
6. 배포 URL에서 교사가 학급을 개설하고 학급 코드를 학생에게 전달합니다.

## 운영 방식
- 교사: 학급 생성 → 관리자 로그인 → 문제 검토/수정 → 단계 변경 → 기록 확인
- 학생: 학급 코드 → 이름/팀 등록 → 문제 4개 작성 → 다른 팀 문제 풀기
- 학급별 데이터는 서로 분리됩니다.
- 교사 화면과 학생 화면은 완전히 분리됩니다.
- 정답은 학생용 조회 응답에 포함되지 않습니다. 채점은 서버 데이터베이스 함수에서 처리합니다.
- 답안 선택 및 정오답 이력이 교사용으로 저장됩니다.
- 문제 선점 90초 경과 시 자동 재출제 대상이 됩니다.

## 주의사항
- 공유용 **초기 버전**입니다. 학생 개인정보 최소화(실명 대신 별칭 권장), 학교 내부 개인정보 지침 검토, 동시 접속 시험을 거쳐 사용하세요.
- 학급 코드와 교사 비밀번호는 충분히 길고 추측하기 어렵게 설정하세요.
- 서버의 `anon` 키는 공개 가능한 키이며, 접근 통제는 SQL 함수의 권한 검증으로 이루어집니다.
- Supabase 무료 프로젝트는 일정 기간 비활성 시 일시 중지될 수 있고 사용량 제한이 있습니다.
